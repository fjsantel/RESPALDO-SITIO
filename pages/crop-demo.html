SIMULACIÓN VIDEO YOUTUBE
(con barras negras arriba y abajo)

</div>

4. Comportamiento Responsive

Las barras se ajustan automáticamente en móviles. Redimensiona la ventana para ver el efecto.

VIDEO RESPONSIVE

5. Implementación con YouTube Real

Ejemplo práctico con un iframe de YouTube:

<div class="crop-container" style="aspect-ratio: 16/9;">
  <iframe src="youtube-video..." style="width: 100%; height: 100%;"></iframe>
  <div class="crop crop-top crop-thin"></div>
  <div class="crop crop-bottom crop-thin"></div>
</div>

📚 Guía de Referencia Rápida

Clases Base:

.crop → Clase base obligatoria
.crop-top → Barra superior
.crop-bottom → Barra inferior
.crop-container → Contenedor helper (recomendado)

Movimiento (píxeles):

.move-up-[1-50] → Mover hacia arriba (ej: move-up-10)
.move-down-[1-50] → Mover hacia abajo (ej: move-down-15)

Movimiento (porcentajes):

.move-up-[5-25]p → Mover hacia arriba % (ej: move-up-10p)
.move-down-[5-25]p → Mover hacia abajo % (ej: move-down-20p)

Colores:

.crop-black → Negro (#000) - por defecto
.crop-white → Blanco (#fff)
.crop-gray → Gris (#666)
.crop-dark → Gris oscuro (#0D1117)

Alturas:

.crop-thin → 15px
.crop-medium → 30px (por defecto)
.crop-thick → 45px
.crop-extra → 60px
.crop-h-[10-50] → Altura específica (ej: crop-h-25)

Utilidades:

.crop-debug → Modo debug (muestra bordes rojos)
.crop-fade-in → Animación de aparición
.crop-slide-in-top → Animación deslizante desde arriba
.crop-slide-in-bottom → Animación deslizante desde abajo

🎨 Personalización con Variables CSS

Puedes personalizar globalmente usando variables CSS:

:root {
  --crop-color: #ff0000; /* Color personalizado */
  --crop-height: 40px; /* Altura personalizada */
  --crop-z-index: 20; /* Z-index personalizado */
}

/* O personalizar instancias específicas: */
.mi-video-especial {
  --crop-color: #0D1117;
  --crop-height: 35px;
}

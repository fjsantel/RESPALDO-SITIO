Solución CSS Para Tu Sitio Web

/* Método 1: Cálculo preciso basado en aspect-ratio */
.video-container {
    position: relative;
    width: 100%;
    height: 400px; /* o usa aspect-ratio: 16/9; */
    overflow: hidden;
    background: #000;
}

.video-container iframe.youtube-video {
    position: absolute;
    top: 50%;
    left: 50%;
    width: 100%;
    height: 56.25vw;
    min-width: 177.78vh;
    min-height: 100%;
    transform: translate(-50%, -50%);
    border: none;
}

/* Método 2: Transform scale (más simple) */
.video-container-simple {
    position: relative;
    width: 100%;
    aspect-ratio: 16/9; /* Moderna y limpia */
    overflow: hidden;
    background: #000;
}

.video-container-simple iframe.youtube-video {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    border: none;
    transform: scale(1.1); /* Ajusta según necesites */
    transform-origin: center;
}

/* Responsive */
@media (max-width: 768px) {
    .video-container iframe.youtube-video {
        width: 120%;
        height: 120%;
        min-width: unset;
        min-height: unset;
    }
    
    .video-container-simple iframe.youtube-video {
        transform: scale(1.15);
    }
}

Recomendación

Método 2 (transform: scale) es más simple y funciona mejor en todos los dispositivos. Solo ajusta el valor de scale según qué tanto recorte necesites:

  • scale(1.1) - Recorte mínimo
  • scale(1.15) - Recorte moderado
  • scale(1.2) - Recorte máximo (elimina casi todas las barras)

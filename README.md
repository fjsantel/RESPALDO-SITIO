## 🎬 Agencia de Contenido Audiovisual en Chile

**Francisco Santelices Ariztía** es una agencia especializada en contenido audiovisual, motion graphics y diseño gráfico. Con más de 10 años de experiencia, creamos contenido visual único para marcas y empresas en Chile y Latinoamérica.

### ✨ Características

- **Diseño Responsivo**: Optimizado para todos los dispositivos
- **Carga Optimizada**: Lazy loading y compresión avanzada
- **Experiencia Interactiva**: Navegación fluida con videos integrados
- **SEO Optimizado**: Meta tags y estructura semántica
- **Performance**: Tiempos de carga ultra-rápidos

### 🚀 Tecnologías

- HTML5 semántico
- CSS3 con variables personalizadas
- JavaScript ES6+ vanilla
- GSAP para animaciones
- YouTube API integrado
- Compresión gzip habilitada

**Francisco Santelices Ariztía** ofrece servicios integrales de contenido audiovisual:

- **🎥 Producción Audiovisual**: Videos corporativos, documentales y contenido para redes sociales
